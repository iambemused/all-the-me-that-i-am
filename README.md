# All The Me That I Am

A cartography of self.
Map the terrain of your life — events, relationships, and world context — across time and layers.

By MoMo Creative · Perth, Western Australia.

## Privacy by architecture

Your map lives entirely in your browser's local storage. Nothing leaves your
device. Private events are never included in any export except a full backup —
this is enforced in the export logic, not by user discretion.

When you want to share something with someone else, you choose what's exported.
What you don't choose stays private.

## How it pairs with The Crossroads

If you want to lay your map alongside someone else's — for shared reflection,
not surveillance — export your **Shared Self** from this app and bring the file
to [The Crossroads](https://the-crossroads.netlify.app). The Crossroads only
ever sees what each person deliberately chose to share.

## Architecture

A single HTML file with React/Babel rendered in the browser. No build step.
To update, edit the HTML directly and push to `main`. Auto-deploys via Netlify.
